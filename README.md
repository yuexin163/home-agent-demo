# home-agent-demo · 壹品居家智能体

当前比赛版本源码位于 [`yipin-ai-web/`](yipin-ai-web/)。

正式演示：<https://yipin-ai.cn>。

## 本地运行

建议安装 Node.js 22 LTS 和 npm。

```bash
cd yipin-ai-web
npm ci
npm run dev
```

完整功能、语音配置和部署操作见 [项目说明](yipin-ai-web/README.md)。

根目录 `index.html` 保留为早期演示。当前比赛版本以腾讯云正式网站和 `yipin-ai-web/` 源码为准；GitHub Pages 不会直接运行 Next.js 源码或语音签名服务。

代码仓库不包含密钥、PDF／Office 原件及比赛交付压缩包。原始资料由项目负责人另外提供，详情见项目说明。
