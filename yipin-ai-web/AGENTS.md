# AGENTS.md

本项目的长期开发规则：

1. 优先保证比赛演示链路稳定。
2. 不开发未经确认的非必要功能。
3. 页面数据通过 `src/data/` 下的统一数据文件管理。
4. 外部 AI 接口不得阻塞基础页面。
5. 不得将接口密钥写入代码。
6. 不得提交大型 Excel、PPT、PDF 和原始图片库。
7. 每次修改后运行 `npm run lint` 和 `npm run build`。
8. 未经要求不要大范围重构。
9. 先完成一条纵向链路，再横向扩展其他空间。
10. 所有页面需要兼容比赛大屏和手机扫码访问。

补充约定：

- 正式资料缺失时必须显示“示意图”“模拟资料”或“待合作方补充”，不得留空或伪装成正式交付资料。
- 页面跳转只能读取助手响应的结构化 `action` 字段，不得解析回复文字。
- 新增空间或材料时，优先新增 JSON 数据并复用现有路由，不要复制整套页面。
- 原始产品库仅允许只读、限量、可中止的轻量检查；批量解析需单独确认。
