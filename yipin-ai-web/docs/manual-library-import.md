## 查询与原文

- 所有16份去重后的PDF均复制到网页项目，并提供网页内原文阅读和新窗口打开入口。

## 重新导入

后续源目录增加或替换说明书后，运行 `scripts/import_manual_library.py` 可重新生成PDF副本、封面、资料索引和页级查询索引。
