# MVP 范围

## 本阶段完成

- 首页户型图与客餐厅热区
- 客餐厅效果示意、方案说明与三类材料卡片
- 地板材料完整详情页
- 文档中心基础框架
- 模拟智能助手接口、结构化动作类型与前端调用封装
- 本地 JSON 数据结构
- 大屏与手机响应式适配
- 产品库轻量结构检查与最多 10 条地板文本样例
- 物料库分类筛选、搜索与限量真实产品样例展示
- 从地板、厨房电器、卫浴中选择6款产品及对应图片验证页面效果

## 第一条完整演示链路

首页 `/` → 客餐厅 `/spaces/living-dining` → 地板物料列表 `/materials?category=地板` → 商品详情 `/products/floor-amber-oak`。

用户也可以在首页输入“查看客餐厅”或“查看客餐厅地板”直接进入相应页面。

## 本阶段暂不完成

- 主卧、次卧、厨房等其他空间的批量页面
- 墙面、柜体材料详情下钻
- 数据库、登录、权限与 CMS
- 真实语音、RAG 与外部 AI 服务
- 复杂 3D 户型和在线文件编辑
- 完整文档解析、工单系统
- 520 MB 产品库的全量解析、批量图片抽取或入库

正式资料缺失处使用明确标注的模拟数据和 CSS 示意图，后续可通过替换统一数据文件及本地静态资源完成升级。
