# 居家智能体简版范围

## 当前资料模块

1. 定制化装修资料：沿用产品库 Excel 已提取的 23 款产品和图片，支持空间、品类、商品三级浏览与搜索。
2. 数字房屋说明书：包含房屋说明书与设备说明书两个二级入口，已接入18份原始PDF。
3. 装修质检：保留正式入口和五阶段资料结构，等待甲方提供验收、问题、照片、整改和复验资料。

## 查询范围

- 房屋说明书名称与原始PDF。
- 厨电、卫浴、暖通和其他四个分区的设备说明书。
- 设备型号、使用、维护建议与可提取PDF正文页码。
- 定制化装修产品名称、品牌、型号、规格与来源。
- 装修质检入口及待补充状态。

## 已屏蔽功能

- 顶部“我的装修方案”入口。
- 商品加入、替换和已选状态。
- 空间页的方案汇总入口。
- 页面底部方案浮层。
- 方案数量、合计和报价入口。

原有 `/my-plan` 页面、方案状态和相关组件仍保留在项目中，未删除；后续需要时可以重新接回导航与商品操作。

## 后续扩展方式

- 新增装修产品：追加产品数据与图片，并把商品 ID 绑定到对应空间资料分类。
- 新增房屋设备：在房屋说明书的 `installedEquipment` 中关联已有产品 ID，并补充安装位置、质保和维护说明。
- 新增纪检资料：按施工阶段添加验收节点、问题记录、现场图片、整改责任和复验结果。
