Yipin Smart Home | Windows Preview Guide

1. Extract the entire ZIP package to a normal local folder.
2. Double-click start-preview.bat.
3. Your default browser will open http://127.0.0.1:4173 automatically.
4. Keep the command window open while using the website.
5. For voice search, use the latest Microsoft Edge or Google Chrome and allow microphone access when prompted.

Important:

- Do not open index.html directly. The local preview launcher is required for page navigation and microphone permissions.
- Voice recognition is provided by Microsoft Edge or Google Chrome and may require internet access. Website content and text queries run locally.
- If Windows Defender asks whether to allow the local preview, allow access only on the private network.
- Close the command window to stop the preview.
